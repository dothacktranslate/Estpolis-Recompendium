# Lufia / Estpolis Recompendium

A cross-platform recompilation and enhancement project for:

- Estopolis Denki I / Lufia & the Fortress of Doom
- Estopolis Denki II / Lufia II: Rise of the Sinistrals

The project aims to preserve the original games while enabling
native execution and optional modern enhancements.

## Status

Early development.

No copyrighted game ROMs are included.
Users must provide legally obtained supported ROM images.
